Personal Flatpak Repository

This repository hosts Flatpak applications for easy installation and automatic updates.

Setup

Add this repository to your system:

flatpak remote-add --user --if-not-exists ljam96-repo https://LJAM96.github.io/flatpak-repo/repo

Available Applications

s-art

Steam Art Manager

flatpak install ljam96-repo io.github.ljam96.sart

cryptomator-gtk

GTK frontend for Cryptomator

flatpak install ljam96-repo io.github.ljam96.cryptomatorgtk

Updates

Applications installed from this repository will update automatically with:

flatpak update

Remove Repository

flatpak remote-delete ljam96-repo
